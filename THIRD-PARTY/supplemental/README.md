# Supplemental license provenance

These packages omit full license texts from their npm archives. The build copies the following texts alongside their original package notices.

- **ApiDOM 1.11.6:** `apidom.LICENSE` and `apidom/LICENSES/` are unchanged copies from [upstream commit 5ccdc1c7abff4a506f4a4096d5916c444a550656](https://github.com/swagger-api/apidom/tree/5ccdc1c7abff4a506f4a4096d5916c444a550656/LICENSES). The package's upstream `NOTICE` names the Apache-2.0, MIT, BSD-3-Clause, and AFL-3.0 texts, which are retained in each bundled ApiDOM component's `LICENSES/` directory.
- **short-unique-id 5.3.2:** `short-unique-id.LICENSE` is the standard Apache-2.0 text. `short-unique-id.NOTICE` preserves the copyright and license statement from its [README at the npm release commit](https://github.com/jeanlescure/short-unique-id/blob/55af179f51d622818db61641200e677b95fbc265/README.md#license).
- **format 0.2.2:** `format.LICENSE` uses the standard MIT text with the package's copyright line from `format.js`: Copyright 2010 - 2013 Sami Samhuri &lt;sami@samhuri.net&gt;. Its package manifest declares MIT.
- **toggle-selection 1.0.6:** `toggle-selection.LICENSE` is an unchanged copy of the [upstream MIT license](https://github.com/sudodoki/toggle-selection/blob/master/LICENSE), retrieved on 2026-10-07. Its npm package manifest declares MIT.
